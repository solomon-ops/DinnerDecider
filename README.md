This is a simple Android application built using Kotlin and XML that helps users decide what to eat for dinner. Users can add new food items and let the app randomly select a meal for them.

Features:

Add new food options easily

Randomly decide dinner from the available choices

User-friendly interface with intuitive buttons


Tech Stack:

Language: Kotlin

UI Design: XML

IDE: Android Studio
